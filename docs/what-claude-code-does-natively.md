# What Claude Code already does

Otto fills gaps, so use the native feature where it covers you.

- `/usage` and the usage page: authoritative limits and billing. Otto's credit figure is an estimate from reported run cost.
- `claude plugin details`: token cost of installed plugins.
- Native scheduling surfaces: Otto observes their output files and cannot see inside them.
- Statusline: the only live source of rate-limit percentages; Otto reads it, it does not replace it.

Otto adds the fleet view: did each automation run, did it leave its output, what did it cost against its own history.
